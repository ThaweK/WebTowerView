🗼 WebTowerView

Lekka aplikacja webowa do wizualizacji 3D lotniska z perspektywy wieży kontroli lotów

▶ Uruchom aplikację 🔑 Pobierz token Cesium

📁 Architektura projektu

✨ Funkcje

Funkcja Opis
🛰️ Widok satelitarny CesiumJS z mapami OpenStreetMap
🏢 Budynki 3D OSM Buildings (wymaga tokenu Cesium Ion)
⛰️ Teren 3D Globalny teren z wysokościami (wymaga tokenu)
🗼 Widok z wieży Stała pozycja kamery, regulowana wysokość
🎥 Kontrola kamery Obrót, pochylenie, zoom myszką i klawiaturą
✏️ Własny overlay Dodawanie pasów startowych, dróg kołowania, apronów
📄 Import GeoJSON Wczytywanie layoutu lotniska z plików
✈️ Samoloty Dodawanie samolotów na współrzędnych geograficznych
🎮 Demo Przykładowe dane lotniska jednym kliknięciem

🚀 Jak uruchomić

Opcja 1: Node.js (npx serve)

npx serve .
# Otwórz http://localhost:3000

Opcja 2: Python

python -m http.server 8000
# Otwórz http://localhost:8000

Opcja 3: Bezpośrednio

Otwórz plik index.html w przeglądarce (niektóre funkcje mogą nie działać z powodu CORS)

🔑 Cesium Ion Token (opcjonalnie)

Dla pełnej funkcjonalności (budynki 3D, teren) potrzebujesz darmowego tokenu:

  1. Zarejestruj się na cesium.com/ion
  2. Wygeneruj Access Token w panelu
  3. Otwórz plik src/js/config.js
  4. Wklej token: 
    CESIUM_ION_TOKEN: 'twój-token-tutaj',
Darmowy tier obejmuje:
• 5 GB storage
• 100 GB streaming/miesiąc
• Globalny teren 3D
• Budynki 3D z OpenStreetMap

📄 Format GeoJSON

Możesz wczytać layout lotniska z pliku GeoJSON:

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "aeroway": "runway", "ref": "09/27" },
      "geometry": {
        "type": "LineString",
        "coordinates": [[20.95, 52.16], [20.98, 52.16]]
      }
    },
    {
      "type": "Feature",
      "properties": { "aeroway": "taxiway", "ref": "A" },
      "geometry": {
        "type": "LineString",
        "coordinates": [[20.95, 52.162], [20.98, 52.162]]
      }
    },
    {
      "type": "Feature",
      "properties": { "aeroway": "apron", "name": "Main Apron" },
      "geometry": {
        "type": "Polygon",
        "coordinates": [[[20.96, 52.163], [20.97, 52.163],
                         [20.97, 52.166], [20.96, 52.166], [20.96, 52.163]]]
      }
    }
  ]
}

Obsługiwane typy (aeroway):

runwayPas startowy
taxiwayDroga kołowania
apronPłyta postojowa
terminalTerminal
hangarHangar
